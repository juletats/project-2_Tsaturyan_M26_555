## Управление таблицами

Примитивная база данных поддерживает создание, просмотр и удаление таблиц с сохранением метаданных в JSON.

### Команды

| Команда                                         | Описание                                            |
|-------------------------------------------------|-----------------------------------------------------|
| `create_table <имя_таблицы> <столбец1:тип> ...` | создать таблицу, автоматически добавляется `ID:int` |
| `list_tables`                                   | показать список всех таблиц                         |
| `drop_table <имя>`                              | удалить таблицу                                     |
| `exit`                                          | выйти из программы                                  |
| `help`                                          | справочная информация                               |

### Поддерживаемые типы данных

- `int` — целое число
- `str` — строка
- `bool` — логическое значение

### Пример использования

```
>>> database

***База данных***

Функции:
<command> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу
<command> exit - выход из программы
<command> help - справочная информация
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: exit
```

В качестве готового примера добавлен файл `db_meta.json` с существующей таблицей users. Её можно посмотреть, удалить,
добавить другую.
Файл `db_meta.json` можно удалить, и база данных создаст его заново при первом использовании.

### Установка и запуск

```bash
uv run ruff check .
uv build
# Запуск базы данных
database
```

### Архитектура

- `core.py` — логика управления таблицами (create, drop, list)
- `engine.py` — основной цикл, парсинг команд, ввод/вывод
- `utils.py` — загрузка и сохранение метаданных в JSON
- `main.py` — точка входа

### Метаданные

Структура таблиц хранится в файле `db_meta.json`:

```json
{
  "users": {
    "columns": {
      "ID": "int",
      "name": "str",
      "age": "int",
      "is_active": "bool"
    }
  }
}
```
